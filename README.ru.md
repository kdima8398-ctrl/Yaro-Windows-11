# Yaro — облегчённая Windows 11 из официального образа

[English](README.md) | **Русский**

Yaro превращает чистую установку **официальной** Windows 11 в лёгкую, тихую и быструю систему:
без рекламы и предустановленного мусора, с минимумом телеметрии и фоновых служб, с настройками
для максимальной производительности в играх и комфортной разработки (Python, WSL2, Docker).

В репозитории **нет пиратских файлов Windows**. Образ скачивается напрямую с официального сайта Microsoft, а Yaro — это файл автоматических ответов (`autounattend.xml`) и продуманные скрипты, которые настраивают систему во время и после установки.

> [!WARNING]
> По умолчанию Yaro **отключает Microsoft Defender, SmartScreen, окна подтверждения UAC, автообновления,
> службу печати, телефонный микрофон Bluetooth-гарнитур и встроенный VPN** и переключает схему питания в
> *Ultimate Performance* (на ноутбуках батарея разряжается быстрее). Прочитайте разделы
> [Что Yaro отключает](#что-yaro-отключает) и [Опции](#опции) до начала установки.
> Сначала протестируйте установку в виртуальной машине. Вы используете скрипты на свой собственный риск.

## Файлы репозитория

| Файл | Описание |
|---|---|
| `autounattend.xml` | Основной файл ответов для чистой автоматической установки Windows 11 с флешки. |
| `Yaro-Remove-Defender-WIM.cmd` | **Автоматическое вырезание/отключение Defender** прямо в файле `install.wim` на флешке ДО установки. |
| `Yaro-Apply.cmd` | Применяет оптимизации Yaro к уже установленной рабочей Windows 11. |
| `scripts/Remove-Defender-Live.cmd` | Пошаговое отключение Defender на уже работающей установленной системе. |
| `scripts/Specialize.ps1` | Системный этап: удаление UWP-приложений, настройка служб, оптимизация реестра и сети. |
| `scripts/FirstLogon.ps1` | Пользовательский этап: отклик интерфейса, проводник, схема Ultimate Performance. |
| `scripts/YaroCommon.ps1` | Конфигурационный файл переключателей `$true` / `$false` для обоих этапов. |
| `scripts/SetWallpaper.ps1` | Установка фирменных минималистичных обоев Yaro на рабочий стол. |
| `assets/` | Баннеры, логотипы и обои 1920×1080 «тетрадный лист» (светлые и тёмные оттенки). |

## Пошаговое руководство по чистой установке (Рекомендуется)

Установка занимает около 10–15 минут и проходит полностью автоматически.

### Шаг 1. Скачайте официальный ISO-образ Windows 11
1. Перейдите на официальный сайт: [microsoft.com/software-download/windows11](https://www.microsoft.com/software-download/windows11).
2. В разделе **«Загрузка образа диска Windows 11 (ISO) для устройств x64»** выберите нужную версию и язык (рекомендуется **English (United States)** либо **Русский**).
3. Скачайте файл `.iso` на компьютер.

### Шаг 2. Запишите установочную флешку через Rufus
1. Вставьте чистую USB-флешку объемом от 8 ГБ.
2. Скачайте бесплатную утилиту [Rufus](https://rufus.ie).
3. В Rufus выберите вашу флешку и укажите скачанный `.iso` образ.
4. Выставьте параметры:
   * Схема раздела: **GPT**
   * Целевая система: **UEFI (non CSM)**
   * Файловая система: **NTFS**
5. Нажмите **«Старт»**.
6. **ВАЖНО:** Когда Rufus откроет всплывающее окно *«Windows User Experience»* (с предложением убрать требования к TPM/RAM/аккаунту), **СНИМИТЕ ВСЕ ГАЛОЧКИ**! Файл ответов Yaro (`autounattend.xml`) уже содержит в себе все необходимые обходы и настройки. Галочки Rufus могут конфликтовать со скриптом.

### Шаг 3. Скопируйте файл ответов Yaro на флешку
1. Скачайте файл **`autounattend.xml`** из этого репозитория.
2. Скопируйте его в **самый корень вашей флешки** (рядом с папками `boot`, `efi`, `sources`).
   *(Путь должен быть именно `E:utounattend.xml`, а не в подпапке).*
3. *(По желанию)* Откройте `autounattend.xml` в Блокноте, если хотите изменить часовой пояс (по умолчанию `FLE Standard Time`), имя пользователя (по умолчанию `User`) или отключить определенные твики (блок `Yaro options`).

### Шаг 4. (Опционально, но рекомендуется) Вырежьте Defender ДО установки
Если вы хотите, чтобы антивирус Microsoft Defender гарантированно никогда не запускался и не грузил систему:
1. Запустите скрипт **`Yaro-Remove-Defender-WIM.cmd`** от имени Администратора.
2. Скрипт автоматически найдёт `sources\install.wim` на подключенной флешке и отключит службы Защитника на уровне ядра до первой загрузки.
3. Подробный разбор смотрите в разделе [Полное вырезание Defender](#полное-вырезание-windows-defender-гайд).

### Шаг 5. Загрузитесь с флешки и запустите установку
1. Перезагрузите компьютер и вызовите меню загрузки (**Boot Menu**).  
   *Обычно это клавиша **F12**, **F11**, **F8**, **Esc** или **Fn+F12** при включении ПК.*
2. Выберите вашу USB-флешку с пометкой **UEFI**.
3. Установщик Windows стартует автоматически. Единственный шаг, где потребуется ваше участие — **выбор диска/раздела для установки**:
   * Внимательно выберите системный диск (SSD), при необходимости отформатируйте его и нажмите «Далее».
4. **Всё остальное Windows сделает сама:**
   * Пропустит экраны создания учетной записи Microsoft, вопросы конфиденциальности, рекламу, выбор региона и требований к интернету.
   * Компьютер сам перезагрузится несколько раз и сразу войдёт на рабочий стол под локальным пользователем `User`.

### Шаг 6. Первые действия после установки
1. **Установите драйверы:** установите драйвер чипсета, сетевой карты и видеокарты (NVIDIA/AMD/Intel) с сайта производителя. Yaro блокирует автоматическую загрузку случайных версий драйверов через Windows Update, чтобы исключить конфликты.
2. **Запустите `Yaro-Apply.cmd` (Рекомендуется):**
   * Скачайте репозиторий (кнопка *Code → Download ZIP* или скопируйте папку со скриптами с флешки) и запустите **`Yaro-Apply.cmd`** от имени Администратора.
   * **Зачем это нужно:** установщики Intel и видеодрайверов часто незаметно возвращают свои службы телеметрии и фонового сбора данных. Запуск `Yaro-Apply.cmd` создаст контрольную точку восстановления, зачистит телеметрию Intel/OEM, окончательно зафиксирует схему питания *Ultimate Performance*, выставит фирменные обои и применит настройки профиля к текущему пользователю.
3. **Просмотр фото и Ножницы (при необходимости):**
   * Если в вашей редакции Windows отсутствовали встроенные приложения или вы устанавливали систему офлайн:
     * **Классический быстрый просмотр фото** (PowerShell от админа):
       ```powershell
       $k = 'HKLM:\SOFTWARE\Microsoft\Windows Photo Viewer\Capabilities\FileAssociations'; foreach ($e in '.jpg','.jpeg','.png','.bmp','.gif','.tiff') { Set-ItemProperty -Path $k -Name $e -Value 'PhotoViewer.FileAssoc.Tiff' }
       ```
     * **Ножницы (Snipping Tool)**:
       ```cmd
       winget install 9MZ95KL8MR0L --accept-package-agreements --accept-source-agreements
       ```
4. **Проверьте логи:** в папке `%SystemRoot%\Setup\Scripts\Yaro\` находятся подробные журналы установки.
5. **Активация:** откройте *Параметры → Система → Активация* и введите свой лицензионный ключ Windows 11 Pro.

### Шаг 7. Дополнительная оптимизация и установка софта через CTT (Chris Titus Tech WinUtil)

Для быстрой пакетной установки нужных программ (без рекламы и мусора) и дополнительной тонкой настройки рекомендуется популярная открытая утилита **CTT Windows Utility (WinUtil)** от Криса Титуса:

1. Откройте **PowerShell от имени Администратора** (`Win + X` → *Терминал (Администратор)*).
2. Введите команду:
   ```powershell
   irm https://christitus.com/win | iex
   ```
3. Откроется графическое окно утилиты:
   * **Вкладка «Install» (Установка софта):** отметьте галочками нужные программы (Chrome/Brave, Telegram, Discord, Steam, 7-Zip, VLC, VS Code, OBS Studio) и нажмите **«Install Selected»**. Winget установит всё чисто в тихом режиме.
   * **Вкладка «Tweaks» (Твики):** выберите пресет **Desktop** (для ПК) или **Laptop** (для ноутбука) и нажмите **«Run Tweaks»**. Твики Yaro и CTT отлично дополняют друг друга.
   * **Вкладка «Updates» (Обновления):** выберите режим **«Security (Recommended)»**, чтобы система получала только стабильные патчи безопасности и не ломалась от сырых крупных обновлений.
   * **Совет:** не нажимайте принудительное отключение всех системных служб — службы Windows уже оптимизированы Yaro.

## Полное вырезание Windows Defender (Гайд)

Многие пользователи сталкиваются с тем, что в Windows 11 Защитник невозможно отключить стандартными твиками: встроенная **«Защита от подделки» (Tamper Protection)** блокирует любые изменения служб даже для учетной записи Администратора и SYSTEM.

В Yaro реализовано два пути полного решения этой проблемы:

```
                                 ┌──────────────────────────────────────────────────┐
                                 │       Как вы хотите отключить Defender?          │
                                 └─────────────────────────┬────────────────────────┘
                                                           │
                        ┌──────────────────────────────────┴──────────────────────────────────┐
                        ▼                                                                     ▼
    ┌────────────────────────────────────────┐                            ┌────────────────────────────────────────┐
    │     ВАРИАНТ 1: ДО УСТАНОВКИ (В WIM)    │                            │    ВАРИАНТ 2: НА УСТАНОВЛЕННОЙ СИСТЕМЕ │
    ├────────────────────────────────────────┤                            ├────────────────────────────────────────┤
    │ ✔ 100% чистый результат без костылей   │                            │ ✔ Без перезаписи флешки                │
    │ ✔ Службы не запустятся НИ РАЗУ         │                            │ ✔ Требуется выключить 2 тумблера в UI  │
    │ ✔ 0 процессов, 0 МБ оперативной памяти │                            │ ✔ Запуск scripts\Remove-Defender-Live  │
    └────────────────────────────────────────┘                            └────────────────────────────────────────┘
```

### Вариант 1. Вырезание из образа WIM до установки (100% результат, рекомендуется)

Когда образ Windows находится на флешке в выключенном состоянии, система безопасности ядра Windows ещё не запущена, а драйвер `WdFilter.sys` не активен. Правка реестра в офлайн-режиме проходит со 100% успехом.

1. Запишите флешку через Rufus (как описано в Шаге 2).
2. Нажмите правой кнопкой мыши по файлу **`Yaro-Remove-Defender-WIM.cmd`** → **«Запуск от имени администратора»**.
3. Скрипт сам найдет файл `sources\install.wim` на флешке (или попросит ввести букву флешки, например `E:`).
4. Программа автоматически:
   * Смонтирует образ через утилиту DISM во временный каталог;
   * Загрузит системные кусты реестра `SYSTEM` и `SOFTWARE`;
   * Выставит режим **`Start = 4` (Disabled)** для служб `WinDefend`, `WdNisSvc`, `Sense`, `SecurityHealthService`;
   * Отключит драйверы уровня ядра `WdFilter` (перехват файлов), `WdBoot` (ранняя загрузка ELAM) и `WdNisDrv`;
   * Применит политики отключения антивируса и скроет значок безопасности в трее;
   * Сохранит изменения в образ `install.wim` и размонтирует его.
5. **Итог:** После установки Windows с этой флешки Защитник **полностью отключён**: процесс `MsMpEng.exe` никогда не появится в Диспетчере задач, диск не будет нагружаться сканированиями, а система освободит 80–150 МБ ОЗУ.

### Вариант 2. Отключение на уже установленной работающей Windows

Если вы уже установили Windows и не хотите переустанавливать систему:
1. Запустите скрипт **`scripts\Remove-Defender-Live.cmd`** от имени Администратора.
2. Скрипт автоматически откроет системное окно настроек *«Безопасность Windows»*.
3. **Вручную переведите в положение «ВЫКЛ» два тумблера:**
   * *Защита в режиме реального времени (Real-time protection)*;
   * *Защита от подделки (Tamper Protection)*.
4. Вернитесь в окно консоли и нажмите любую клавишу: скрипт отключит политики, остановит службы Defender и удалит значок из автозагрузки.
5. Перезагрузите компьютер.

## Применение к уже установленной Windows (Yaro-Apply.cmd)

Если у вас уже стоит официальная Windows 11, и вы хотите очистить её от мусора и применить оптимизации Yaro:

1. Нажмите **Code → Download ZIP** на странице репозитория и распакуйте архив в удобную папку.
2. Запустите **`Yaro-Apply.cmd`** от имени пользователя, которого хотите настроить (потребуются права Администратора).
3. Скрипт создаст точку восстановления системы, удалит предустановленные UWP-приложения, оптимизирует реестр, применит профиль питания *Ultimate Performance* и ускорит меню.
4. Перезагрузите компьютер.

## Конфигурация и опции (Yaro options)

Для тонкой настройки системы отредактируйте переменные в начале `autounattend.xml` (для чистой установки) или в файле `scripts/YaroCommon.ps1` (для `Yaro-Apply.cmd`). Значение `$true` включает твик, `$false` — отключает.

| Переключатель | По умолчанию | Описание |
|---|:---:|---|
| `$DisableDefender` | `$true` | Отключает Microsoft Defender (включая `MDCoreSvc`, `webthreatdef*`, `wscsvc` и `Sense.Client`) и скрывает значок из трея. |
| `$DisableSmartScreen` | `$true` | Отключает фильтр SmartScreen при запуске скачанных файлов и программ. |
| `$SilentUAC` | `$true` | Программы запускаются с правами администратора без затемнения экрана и всплывающего окна подтверждения. |
| `$PauseUpdates` | `$true` | Отключает автоматическое обновление и замораживает обновления до 2077 года (Ghost Pause), сохраняя работу Store и `winget`. |
| `$DisablePrinting` | `$true` | Отключает службу диспетчера печати и `PrintWorkflowUserSvc` (если у вас нет принтера). |
| `$DisableBtHandsFree` | `$true` | **Защита звука Bluetooth:** отключает режим гарнитуры Hands-Free. В играх со звуковым чатом (CS2, Discord, Grounded) звук в AirPods/наушниках остаётся кристально чистым Hi-Fi Stereo (48 кГц). |
| `$DisableVPN` | `$true` | Отключает встроенные устаревшие службы VPN (RasMan/RasAuto). |
| `$DisableWindowsAI` | `$true` | Удаляет Copilot / `CoreAI`, отключает компонент `Recall` и ИИ-функции в новом Блокноте. |
| `$DebloatEdge` | `$true` | Отключает боковую панель Copilot/Bing, Shopping Assistant, Rewards, рекомендации, автозапуск и телеметрию Edge через политики. |
| `$RemoveOneDrive` | `$true` | Удаляет OneDrive через `OneDriveSetup.exe /uninstall` и отключает `OneSyncSvc` (дополнительно к блокировке синхронизации). |
| `$EnablePhotoViewer` | `$true` | Регистрирует классический быстрый «Просмотр фотографий Windows» для `.jpg`, `.png`, `.bmp`, `.gif`, `.ico` и др. |
| `$DisableBgApps` | `$true` | Запрещает UWP-приложениям из Microsoft Store работать в фоне. |
| `$PreferIPv4` | `$true` | Задаёт приоритет IPv4 над IPv6 (`DisabledComponents = 32`), не отключая IPv6 полностью (безопасно для WSL2 и игр). |
| `$DisableSearchIndex` | `$false` | Отключает службу индексирования `WSearch` (включайте, если используете сторонний поиск вроде Everything). |
| `$DisableHibernation` | `$false` | Полностью отключает гибернацию (`powercfg /h off`) для экономии места на десктопах. *Быстрый запуск (`HiberbootEnabled = 0`) отключается всегда.* |
| `$RemoveIntelApp` | `$false` | Удаляет `AppUp.IntelGraphicsExperience` (Intel Graphics Command Center) и службу `igccservice`. |
| `$ArgonPerformance` | `$true` | Комплекс твиков производительности: план *Ultimate Performance*, минимальная частота CPU 5% (процессор не перегревается в простое), объединение процессов SvcHost (снижение с 90+ до ~55 процессов), ускорение отклика окон `MenuShowDelay = 0`. |
| `$ForceMSI` | `$false` | Перевод видеокарты, накопителя NVMe и сетевых карт в режим прерываний MSI (Message Signaled Interrupts) для снижения DPC-задержек. |
| `$SetWallpaper` | `$true` | Автоматическая установка фирменных минималистичных обоев Yaro. |

## Что именно меняет и оптимизирует Yaro

### Удаляемый софт, ИИ и мусор
* Полностью вырезаются рекламные и партнерские приложения: Clipchamp, Microsoft News, Weather, Feedback Hub, DevHome, Bing Search, Copilot / `CoreAI`, Edge GameAssist, Cortana, Solitaire, Office Hub, People, новый Outlook и потребительские промо-пакеты.
* Блокируется скрытый самовозврат `Outlook` и `DevHome` планировщиком `UScheduler_Oobe` после выхода в сеть, очищаются закрепления меню Пуск при чистой установке и скрываются рекламные баннеры аккаунта Microsoft.
* Отключены сбор телеметрии (в т.ч. `AdvertisingInfo`, `TIPC`, `TailoredExperiences`, `Start_TrackProgs`, `Siuf`), служба `whesvc`, геолокация `lfsvc`, отправка отчётов WER (`QueueReporting`, при этом локальные дампы сохраняются) и задачи телеметрии `Flighting` / `CEIP` / `Diagnosis`.

### Скорость, отклик и интерфейс
* **SvcHost Grouping:** порог разделения процессов увеличен (`SvcHostSplitThresholdInKB = 0xffffffff`), что сокращает число системных процессов почти в два раза.
* **WinTrust Fix:** исправлена 2-минутная задержка при установке драйверов и программ из-за таймаутов проверки сертификатов (`State = 0x23C00` + `ChainEngine` 200/500 мс).
* **Проводник и комфорт:** `MenuShowDelay = 0` мс, кнопка «Завершить задачу» на панели задач (`TaskbarEndTask`), классическое контекстное меню Windows 10, открытие на «Этот компьютер» (`LaunchTo = 1`), скрыты «Главная» и «Галерея», всегда видны расширения файлов (`HideFileExt = 0`), отключено залипание клавиш (`StickyKeys = 506`), отключён Быстрый запуск (`HiberbootEnabled = 0`) и включён подробный BSoD.
